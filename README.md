# NOTICE: All of my personal projects have been moved from GitHub to [Codeberg](https://codeberg.org/muelsyse).

## I would highly encourage others to - if they are able to - jump ship from GitHub to truly FOSS options like [Codeberg](https://codeberg.org/), [Sourcehut](https://sourcehut.org/) and [Disroot](https://disroot.org/services/git). Consider [self-hosting](https://forgejo.org/docs/latest/admin/installation/) a Forgejo instance too.

### Why?
GitHub is increasingly being enshittified by Microsoft. While its downfall has been long coming, Microslop is going on a generational run of turning everything it touches into [steaming](https://www.zdnet.com/article/why-people-hate-windows-11/) [piles](https://www.theregister.com/2026/03/26/github_ai_training_policy_changes/) [of](https://caio.ca/blog/the-downfall-and-enshittification-of-microsoft.html) [dung](https://github.com/orgs/community/discussions/159749) and Github as a platform for developers is becoming close to untenable. It's about time people make the switch.
